# Enregistrement — instructions techniques

1) Préparer l'environnement
- Active ton venv conda/virtualenv et installe les requirements
- Ouvre JupyterLab ou Jupyter Notebook et charge les notebooks nécessaires

2) OBS : configuration rapide
- Sources : Screen capture (notebook), optional Microphone (USB)
- Paramètres : output format mp4, encoder x264, bitrate 3500 kbps, audio 128 kbps
- Enregistrer en segments : appuie sur Start Recording, exécute la partie 1 (intro+perceptron), arrête, répète pour la partie suivante — cela facilite le montage

3) Conseils audio
- Enregistre dans un endroit calme
- Garde une distance stable du micro (10–20 cm)
- Parle lentement et clairement, fais des pauses entre phrases

4) Montage & sous-titres
- Importer les clips dans Shotcut/OpenShot
- Ajouter titres et transitions simples
- Pour sous-titres, utiliser le script .srt que je peux générer si demandé

5) Upload
- Exporter mp4 à 720p, nommer : rn_basics_01_intro_mlp.mp4
- Pousser vers GitHub (release) ou héberger sur YouTube/Drive et partager le lien
